
# Новый Путь — Крым

Сайт Содружества центров реабилитации в Крыму. Бесплатная, бессрочная, анонимная помощь зависимым и их близким.

## 📁 Структура проекта

```
/
├── index.html    # Разметка страницы
├── style.css     # Стили (сезонные темы, адаптив, анимации)
├── code.js       # Логика: модалки, тренажёры, формы, сезоны
└── README.md     # Документация (этот файл)
```

## 🚀 Запуск

Сайт полностью статический — не требует сборки или сервера.

1. Скачайте все файлы в одну папку.
2. Откройте `index.html` в браузере.

Для локальной разработки с «живой» перезагрузкой:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## 🧩 Что внутри

### Основные секции

- **Hero** — заголовок, бейджи (Бесплатно / Бессрочно / Анонимно), CTA-кнопки.
- **Для кого мы** — три карточки (зависимым, близким, вышедшим в новую жизнь).
- **Что мы делаем** — 4 направления помощи.
- **Почему нам доверяют** — статистика + отзывы.
- **Как получить помощь** — 3 шага.
- **Контакты** — телефон, мессенджер, регион.
- **Подвал** — навигация, документы, контакты, сезонные темы.

### Психологические тренажёры (панель под шапкой)

- 🌊 **Сёрфинг желания** — упражнение на основе mindfulness. Учит переживать тягу как волну, не действуя по ней. 5 шагов, оценка до/после, автоматический расчёт снижения. Счётчик запускается кнопкой «▶ Запустить счётчик».
- 🧭 **Карта триггеров** — КПТ-опросник. Помогает увидеть личные триггеры и составить «план Б» для каждого. 5 шагов, мультивыбор, итоговая карта.
- 🫁 **Дыхание SOBER** — 1-минутная практика (3 цикла: вдох 4 с — задержка 2 с — выдох 6 с). Снижает тревогу и импульсивность. Анимированный круг + оценка состояния.

### Модалки «3 клика»

- **Что мы делаем** — 3 шага по услугам.
- **Почему нам доверяют** — 3 шага по статистике.
- **Как получить помощь** — 3 шага по началу.

### Форма обратной связи

- Поля: имя (опционально), телефон (обязательно), кто вы (обязательно), комментарий (опционально), капча-сумма, чекбокс согласия на обработку ПД (обязательно).
- Отправка через `formsubmit.co` с fallback на `mailto:`.
- Honeypot-поле против спама.
- Без галочки согласия форма не отправляется.

### Сезонные темы

Четыре темы: `winter`, `spring`, `summer`, `autumn`. Переключаются в подвале. Выбор сохраняется в `localStorage`. Автоопределение по месяцу при первом визите.

## 🛠 Технологии

- Чистый HTML / CSS / JavaScript (ES5+).
- `<dialog>` для модалок с fallback через `[open]`.
- CSS-переменные для сезонных тем.
- `IntersectionObserver` для анимации появления (`.reveal`).
- `prefers-reduced-motion` — отключение анимаций.
- `env(safe-area-inset-*)` — поддержка «чёлки» на iOS.

## ♿ Доступность

- Семантическая разметка (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`).
- `aria-label`, `aria-labelledby`, `role="button"` где нужно.
- Управление фокусом при открытии/закрытии модалок.
- Клавиатурная навигация (`Enter` / `Space` для `role="button"`).
- Контрастные фокус-обводки (`:focus-visible`).

## 📱 Адаптивность

- Mobile-first, брейкпоинты: `360px`, `480px`, `640px`, `768px`.
- Сейф-зоны для iOS (`env(safe-area-inset-*)`).
- Панель тренажёров сжимается на мобильных (скрывается подпись, уменьшаются кнопки).

## 🔐 Приватность

- Данные тренажёров не отправляются на сервер — всё в памяти браузера.
- Форма отправляет только имя, телефон, роль и комментарий.
- Honeypot + капча-сумма против ботов.
- Обязательное согласие на обработку ПД (чекбокс) перед отправкой формы.

## 📄 Документы

В подвале доступны:

- Политика конфиденциальности
- Пользовательское соглашение
- Согласие на обработку ПД
- Отказ от ответственности
- Правила оказания помощи
- Администраторам

Все документы открываются в модальном окне без перезагрузки страницы.

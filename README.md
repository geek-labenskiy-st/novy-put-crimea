## 🚀 Запуск

Сайт полностью статический — не требует сборки или сервера.

1. Скачайте все файлы в одну папку.
2. Откройте `index.html` в браузере.

Для локальной разработки с «живой» перезагрузкой:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## 🧩 Что внутри

### Основные секции

- **Hero** — заголовок, бейджи (Бесплатно / Бессрочно / Анонимно), CTA-кнопки.
- **Для кого мы** — три карточки (зависимым, близким, вышедшим в новую жизнь).
- **Что мы делаем** — 4 направления помощи.
- **Почему нам доверяют** — статистика + отзывы.
- **Как получить помощь** — 3 шага.
- **Контакты** — телефон, регион, обратная связь.
- **Подвал** — навигация, документы, контакты, сезонные темы.

### Психологические тренажёры (панель под шапкой)

- 🌊 **Сёрфинг желания** — 5 шагов, оценка до/после, автоматический расчёт снижения.
- 🧭 **Карта триггеров** — КПТ-опросник, 5 шагов, мультивыбор, итоговая карта, план Б.
- 🫁 **Дыхание SOBER** — 3 цикла: вдох 4 с — задержка 2 с — выдох 6 с.

Состояние тренажёров сбрасывается при повторном открытии модалки.

### Модалки «3 клика»

- **Что мы делаем** — 3 шага по услугам.
- **Почему нам доверяют** — 3 шага по статистике.
- **Как получить помощь** — 3 шага по началу.

### Форма обратной связи

- Поля: имя (опционально), телефон (обязательно), кто вы (обязательно), комментарий (опционально), капча-сумма, чекбокс согласия на обработку ПД (обязательно).
- Отправка через formsubmit.co с fallback на `mailto:`.
- Honeypot-поле против спама.

### Сезонные темы

- Четыре темы: `winter`, `spring`, `summer`, `autumn`. Переключаются в подвале.
- Выбор сохраняется в localStorage. Автоопределение по месяцу при первом визите.
- Сезонные частицы падают в фоне секций.

## 🛠 Технологии

- Чистый HTML / CSS / JavaScript (ES5+).
- `&lt;dialog&gt;` для модалок с fallback через `[open]`.
- CSS-переменные для сезонных тем.
- IntersectionObserver для анимации появления (`.reveal`).
- `prefers-reduced-motion` — отключение анимаций.
- `env(safe-area-inset-*)` — поддержка «чёлки» на iOS.

## ♿ Доступность

- Семантическая разметка.
- `aria-label`, `aria-labelledby`, `role="button"` где нужно.
- Управление фокусом при открытии/закрытии модалок (фокус per-dialog).
- Клавиатурная навигация (Enter / Space для `role="button"`).
- Контрастные фокус-обводки (`:focus-visible`).

## 📱 Адаптивность

- Mobile-first, брейкпоинты: 360px, 400px, 480px, 640px, 768px, 900px.
- Сейф-зоны для iOS (`env(safe-area-inset-*)`).
- Панель тренажёров сжимается на мобильных (2 ряда кнопок на очень узких экранах).
- Навигация в шапке показывается с ≥900px.

## 🔐 Приватность

- Данные тренажёров не отправляются на сервер — всё в памяти браузера.
- Форма отправляет только имя, телефон, роль и комментарий.
- Honeypot + капча-сумма против ботов.
- Обязательное согласие на обработку ПД (чекбокс) перед отправкой формы.
